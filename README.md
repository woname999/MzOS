# MzOS

## About

MzOS is a Debian-based Linux distribution project.

The first objective is to create a stable KDE Plasma gaming-oriented operating system.

## Vision

A modular Debian platform designed around:

- Stability
- Usability
- Gaming compatibility
- Hardware diagnostics
- User control

## Current Status

🚧 Early development

## Goals

- Gaming optimized Debian base
- Hardware and software Health Check
- Modular architecture
- Reproducible builds

## Philosophy

Install it.
Understand it.
Master it.
