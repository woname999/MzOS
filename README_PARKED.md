# MzOS

> ## ⏸️ Project Status: PARKED
>
> Active development of MzOS is currently paused.
>
> The repository is being preserved for a possible future resumption of the project. MzOS is **not considered abandoned or deleted**.
>
> One of the main blockers is the current compatibility gap between Linux and competitive gaming.
>
> Several major competitive games rely on publisher-controlled anti-cheat policies or security models that do not support Linux, or explicitly prevent Linux clients from playing. This currently prevents MzOS from achieving one of its original goals: providing a Linux gaming environment suitable for competitive games without major compatibility compromises.
>
> MzOS will **not attempt to bypass, disable, evade, or work around anti-cheat protections or publisher security policies**.
>
> Development may be reconsidered if support for Linux in the competitive-gaming ecosystem improves sufficiently in the future.

---

## About

MzOS is a Debian-based Linux distribution project.

The first objective is to create a stable KDE Plasma gaming-oriented operating system.

## Vision

A modular Debian platform designed around:

* Stability
* Usability
* Modern gaming compatibility
* Hardware diagnostics
* User control and a friendly experience

## Current Status

⏸️ **Parked**

Development is paused pending meaningful improvement in Linux compatibility for competitive games and their anti-cheat requirements.

The existing repository is preserved as a technical and architectural foundation for a possible future restart.

## Goals

* Gaming-optimized Debian base
* Hardware and software Health Check
* Modular architecture
* Reproducible builds

## Philosophy

Install it.
Understand it.
Master it.

## First Edition

### MzOS Gaming

Target:

* KDE Plasma desktop
* Gaming-optimized environment
* Steam compatibility
* Proton support
* Hardware Health Check

## Project Principles

* Stability before experimentation
* Documentation before automation
* Reproducibility before convenience
* Compatibility before optimization
* Respect anti-cheat and publisher security policies rather than attempting to bypass them

## Future

If competitive gaming support on Linux improves enough to make the original project goals realistic again, MzOS may be resumed.

Before active development restarts, the repository should first undergo a cleanup and modernization pass, including reproducible build tooling and a proper Clone-to-Build workflow.
