# ADR 0001 — Philosophie du projet MzOS

Date : 2026-07-17

## Statut

Accepté

## Contexte

MzOS est un projet de distribution Linux basée sur Debian.

L'objectif initial est de créer une distribution Gaming orientée stabilité, simplicité et compatibilité.

## Décision

MzOS sera construit selon les principes suivants :

- Debian Stable comme fondation.
- KDE Plasma comme environnement principal.
- Architecture modulaire.
- Documentation avant automatisation.
- Reproductibilité des installations.
- Compatibilité avant optimisation expérimentale.
- Health Check hardware et software intégré.

## Conséquences

Cette approche privilégie la stabilité et la maintenance à long terme plutôt que la recherche de performances maximales.
